# Forge Cursos 🎓

Site de plataforma fictícia de cursos online, com design profissional e totalmente responsivo. O projeto simula uma experiência completa de navegação em um portal educacional, com catálogo de cursos, fluxo de matrícula e área de contato.

## ✨ Funcionalidades

- **Navbar responsiva** com scroll spy e menu hambúrguer para mobile
- **Carrossel hero** em tela cheia com legendas e auto-play
- **Seção de diferenciais** com ícones (estudos flexíveis, ritmo próprio, multiplataforma)
- **Catálogo de cursos** com navegação por abas (Culinária, Mecânica e Técnico)
- **9 modais de detalhes** por curso, com descrição, duração, nível e preço
- **Modal de Login e Registro** com validação de campos
- **Formulário de contato** com campos de nome, e-mail, telefone e mensagem
- **Card de informações** com endereço, horário e canais de atendimento
- **Footer completo** com links rápidos, redes sociais e informações de contato

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5 (local)
- Bootstrap Icons

## 🚀 Como rodar

Basta abrir o `index.html` diretamente no navegador — sem dependências de build!
